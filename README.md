# Teen Tabahi

Teen Tabahi is a semester project we built as a team.  
It gives visitors a taste of the restaurant, showcases its menu, and makes it easy to explore what’s on offer.

We’re currently rebuilding it, so parts of the project may still be changing or incomplete.

## Getting started

You’ll need [Node.js](https://nodejs.org/) installed. Clone the repository and install its dependencies:

```bash
git clone https://github.com/tahaa1i/teen-tabahi.git
cd teen-tabahi/server
```

Check `server/package.json` for the available scripts, then run the appropriate command:

```bash
npm run
```

## Project structure

- `index.html` — main page
- `component/` — reusable page components
- `data/` — project data
- `images/` — image assets
- `js/` — JavaScript
- `server/` — server-related files
- `stylesheet/` — stylesheets
